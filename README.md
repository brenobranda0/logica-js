📘 Resolução dos Desafios – Curso de Lógica de Programação

Este repositório contém a resolução dos desafios propostos no curso de Lógica de Programação, abordando conceitos fundamentais para o desenvolvimento de software.

🚀 Objetivo

Praticar lógica de programação utilizando conceitos essenciais como:

✅ Variáveis

✅ Condicionais (if-else)

✅ Estruturas de repetição (while)

✅ Interação com o usuário (alert, prompt)

✅ Uso de console.log

✅ Template Strings

Esses fundamentos são indispensáveis para resolver problemas de forma estruturada, tomar decisões no código, criar iterações controladas e interagir eficazmente com usuários.

Compreender esses conceitos:

Melhora a capacidade de depuração

Ajuda a criar soluções inovadoras

Garante maior qualidade no desenvolvimento de software

Investir nesses princípios é essencial para construir uma base sólida na programação.

🧠 Desafios e Respostas
1️⃣ Verificar o dia da semana

Pergunta ao usuário qual é o dia da semana.
Se for Sábado ou Domingo, exibe "Bom fim de semana!".
Caso contrário, exibe "Boa semana!".

diaDaSemana = prompt('Qual é o dia da semana?');

if (diaDaSemana == 'Sábado') {
    alert('Bom fim de semana!');
} else if (diaDaSemana == 'Domingo') {
    alert('Bom fim de semana!');
} else {
    alert('Boa semana!');
}
2️⃣ Número positivo ou negativo

Solicita ao usuário um número e informa se ele é positivo ou negativo.

numero = prompt('Digite um positivo ou negativo');

if (numero > 0) {
    alert('Número positivo!');
} else {
    alert('Número negativo!');
}
3️⃣ Sistema de pontuação de jogo

Verifica se a pontuação é maior ou igual a 100.
Se for, o jogador vence. Caso contrário, deve tentar novamente.

pontuacao = 105;

if (pontuacao >= 100) {
    console.log('Parabéns, você venceu!');
} else {
    console.log('Tente novamente para ganhar.');
}
4️⃣ Exibir saldo da conta

Mostra o saldo usando Template String.

let saldoConta = 500; // Exemplo de saldo
alert(`Seu saldo é de R$${saldoConta}.`);
5️⃣ Mensagem de boas-vindas

Solicita o nome do usuário e exibe uma mensagem personalizada.

let nome = prompt('Qual o seu nome?');
alert(`Boas vindas ${nome}`);
